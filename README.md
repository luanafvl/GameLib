# GameLib

GameLib is a responsive landing page designed to help gamers keep track of their games across multiple platforms in one place.

The goal of the project is to create a modern UI inspired by game storefronts and game library managers, allowing users to visualize how a centralized platform for managing games could look.


---


## Features

* 📱 Responsive layout
* 🎮 Game showcase cards with hover effects
* 🧭 Smooth navigation between sections
* 🌌 Modern gaming UI design
